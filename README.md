# Greedy Whalebuffet

[![CI](https://github.com/esainane/greedywhalebuffet/actions/workflows/validate.yml/badge.svg?branch=master)](https://github.com/esainane/greedywhalebuffet/actions/workflows/validate.yml)

Source for [Greedy Whalebuffet Website](https://greedy.antihype.space/).

Generates scripts for use in the [BotC app](https://botc.app/), including optional quirks and character bans. Provides a reference for new and changed characters and jinxes.

For changes to the script, see the [CHANGELOG](CHANGELOG.md).

## Installation

Install dependencies with:

- `npm ci`

## Running

Start locally with:

- `npm start`
